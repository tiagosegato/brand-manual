02 · Gradientes

Gradientes de cor

Usados em textos de destaque, logos e elementos visuais especiais. Nunca em fundos de seção inteira.

Azul → Roxo (principal)
linear-gradient(135deg, #4682A0 0%, #464BA1 100%)
→ Títulos em destaque (h1 strong), logo "ts"
accent-2 → purple-2 (vibrante)
linear-gradient(135deg, #2997FF 0%, #BF5AF2 100%)
→ Detalhes de destaque vibrante, em áreas pequenas
Como aplicar gradiente em texto (CSS)
background: linear-gradient(135deg, #4682A0 0%, #464BA1 100%);
-webkit-background-clip: text;
-webkit-text-fill-color: transparent;
background-clip: text;
03 · Efeitos de luz

Glows radiais

Halos de luz com gradientes radiais atrás do conteúdo. Dão profundidade sem poluir: no máximo um par por tela.

Glow azul
glow-blue · 700 × 500
radial-gradient(ellipse at center,
  var(--glow-blue) 0%, transparent 70%)
escuro: rgba(70,130,160, .15)
claro: rgba(70,130,160, .32)
Glow roxo
glow-purple · 400 × 300
radial-gradient(ellipse at center,
  var(--glow-purple) 0%, transparent 70%)
escuro: rgba(191,90,242, .08)
claro: rgba(191,90,242, .24)
Glow de capa
Glow de capa · azul + roxo fundidos no centro
Fundo de todas as capas de slides. Dois halos grandes que se fundem no meio e somem nas bordas.
radial-gradient(ellipse 32% 45% at 37% 41%, rgba(70,130,160, .58) 0%, transparent 100%),
radial-gradient(ellipse 32% 45% at 63% 59%, rgba(70,75,161, .55) 0%, transparent 100%)
escuro: azul .45 · roxo .50
Regra de uso: glows sempre com pointer-events: none e position: absolute dentro de um container com overflow: hidden. Use os valores dos tokens glow-blue e glow-purple: no tema claro eles são mais fortes de propósito, para o halo aparecer sobre o fundo claro.

Scroll Reveal — Intersection Observer
/* CSS */
.reveal { opacity: 0; transform: translateY(28px);
  transition: opacity .65s ease, transform .65s ease; }
.reveal.visible { opacity: 1; transform: translateY(0); }
.reveal-delay-1 { transition-delay: 0.1s; }

/* JS */
const obs = new IntersectionObserver(entries => {
  entries.forEach(e => { if (e.isIntersecting) e.target.classList.add('visible'); });
}, { threshold: 0.1 });
document.querySelectorAll('.reveal').forEach(el => obs.observe(el));
