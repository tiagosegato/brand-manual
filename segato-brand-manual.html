02 · Gradientes

Gradientes de cor

Usados em textos de destaque, logos e elementos visuais especiais. Nunca em fundos de seção inteira.

Azul → Roxo (principal)
linear-gradient(135deg, #4682A0 0%, #464BA1 100%)
→ Títulos em destaque (h1 strong), logo "ts"
Azul Comp. → Roxo Comp.
linear-gradient(135deg, #2997ff 0%, #bf5af2 100%)
→ Elementos de destaque vibrante, hero glows
Azul → Roxo (vertical)
linear-gradient(180deg, #4682A0 0%, #464BA1 100%)
→ Botões, badges coloridos, ícones de redes sociais
Roxo → Roxo Comp.
linear-gradient(135deg, #464BA1 0%, #bf5af2 100%)
→ Hover states especiais, efeitos de luz roxo
Como aplicar gradiente em texto (CSS)
background: linear-gradient(135deg, #4682A0 0%, #464BA1 100%);
-webkit-background-clip: text;
-webkit-text-fill-color: transparent;
background-clip: text;
03 · Efeitos de luz

Glows radiais

Halos de luz criados com gradientes radiais posicionados absolutamente. Dão profundidade e atmosfera sem poluir o conteúdo. Passe o mouse sobre os cards para ver cada efeito.

Glow azul
Hero Glow — Azul primário
position: absolute; width: 800px; height: 800px;
background: radial-gradient(
  ellipse at center,
  rgba(70,130,160, 0.14) 0%, transparent 70%
);
top: 50%; left: 50%; transform: translate(-50%, -60%);
Glow roxo comp.
Hero Glow 2 — Roxo complementar
position: absolute; width: 500px; height: 300px;
background: radial-gradient(
  ellipse at center,
  rgba(191,90,242, 0.10) 0%, transparent 70%
);
bottom: 10%; right: 5%;
Combinado
Hero — Azul + Roxo Comp. juntos
/* Use os dois glows acima sobrepostos */
/* Opacidade recomendada:
  azul: 0.10–0.16
  roxo: 0.07–0.10
  light mode: reduza ~30% */
Glow roxo comp.
Glow roxo complementar isolado
background: radial-gradient(
  ellipse at center,
  rgba(191,90,242, 0.12) 0%,
  transparent 65%
);
/* Para seções de destaque especial */
Regra de uso: Os glows devem ter pointer-events: none e nunca ultrapassar opacidade 0.20 no dark e 0.14 no light. Posicione-os com position: absolute dentro de um container com overflow: hidden.

Scroll Reveal — Intersection Observer
/* CSS */
.reveal { opacity: 0; transform: translateY(28px);
  transition: opacity .65s ease, transform .65s ease; }
.reveal.visible { opacity: 1; transform: translateY(0); }
.reveal-delay-1 { transition-delay: 0.1s; }

/* JS */
const obs = new IntersectionObserver(entries => {
  entries.forEach(e => { if (e.isIntersecting) e.target.classList.add('visible'); });
}, { threshold: 0.1 });
document.querySelectorAll('.reveal').forEach(el => obs.observe(el));
